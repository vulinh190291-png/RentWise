- [父 POM](../../../pom.xml)确认 Java 17、Spring Boot 3.5.16 和三个 Maven 子模块；[前端依赖](../../../frontend/package.json)确认 Vue / TypeScript / Vite。
- [本地 ProfileService](../../../learning-service/src/main/java/com/rentwise/profile/service/ProfileService.java)在 remote-enabled=false 或该属性缺失时启用（matchIfMissing=true；当前 application.yml 默认仍为 true）；[测试配置](../../../learning-service/src/test/resources/application-test.yml)使用该模式，因此不能用本地测试证明跨服务链路。
