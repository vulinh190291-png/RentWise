本轮执行用户明确允许的地图降级方案，交付公开 `/explore` 城市列表与详情。既有独立分支 `feat/explore-city-map` 已位于合并 PR #11 后的干净基线，无需重建或改写分支。

## 方案

地图 SDK + 服务底图适合最终地图，当前尚无项目授权、Key、域名配置及上线核验。开源引擎 + 自带 GeoJSON 不能解决数据许可与中国版图问题，排除来源不明数据。采用列表与侧栏作为当前版本，不安装地图依赖、不放地图轮廓或假坐标；以技术报告记录后续接入条件。

暖白、石墨黑、系统字体延续 UI 0.1.1；首页增加公开入口，Dashboard 增加入口。城市样本独立 JSON，按需请求并验证结构；源码维护类型、搜索与加载逻辑。每条事实对应来源，风险提示为编辑提出的现场观察问题，不声明某城市风险率或法律结论。复用既有授权照片仅作全页空间观察参考，明确不是任何城市实景。

桌面为城市列表与详情并排；手机初始显示列表，选择城市后进入详情，返回恢复按钮焦点。原生按钮支持 Tab/Enter/Space，详情标题接收焦点，Escape 返回。空搜索不保留误导性旧详情；数据加载失败可重试；地图入口明确显示尚未开放原因。

## 重点边界

移动端长文本、无结果时旧选中项、加载中离开页面、无效 JSON/重复 ID、失败后重试和焦点恢复都需覆盖。地图节点、缩放、地图/列表切换的真实地图部分不宣称完成。无真实业务写入回归时必须明确区别于历史真实服务验收。
