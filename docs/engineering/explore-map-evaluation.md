## 本轮决定

交付城市列表和详情，不装地图依赖、不请求地图瓦片、不绘制中国轮廓或伪地理节点。用户明确允许在授权、Key 或部署条件未具备时降级。本轮没有已确认的项目地图服务授权、域名配置和可验证的 Key；不查找系统中其他项目的密钥，不使用网上示例密钥。地图选择、缩放及移动地图/列表切换仍未实现。

## 方案比较

| 方案 | 数据、授权与 Key | Vue 3 与交互 | 性能/移动端 | 世界扩展 |
| --- | --- | --- | --- | --- |
| 高德 JS API 2.0 | 服务商底图；需应用 Key 和安全配置，须核对项目使用场景、额度与条款 | 原生 SDK 可在 mounted 初始化、卸载时销毁；标记事件同步选中城市，地图中心/缩放联动侧栏 | SDK/外部网络增加开销；触摸能力需设备验证，不承诺实测帧率 | 平台有世界地图产品入口，但覆盖、授权、坐标与能力需独立确认 |
| 天地图 JS API 4.0 | 官方平台，申请服务许可 Key；域名、额度和服务条件待控制台核对 | SDK 地图与标记可封装为 Vue 组件；全国站文档本轮超时，不能宣称完整 API 验证通过 | 网络与瓦片开销待实测；移动交互要验证触摸冲突 | 全球底图资源可作为候选，但不可据此推断所有世界内容可任意再分发 |
| Leaflet + 获许可底图 | 引擎开源，BSD-2-Clause；不自带可用于本项目的地图数据授权；Key 由底图商决定 | 标记、弹窗、缩放与事件适合八城市侧栏联动；不必增加 Vue 包装依赖 | 官方强调轻量和移动端；实际应用仍需测瓦片、网络、内存与触摸 | 可换全球底图，须分别核实数据与境界表达 |
| MapLibre GL JS + 获许可矢量瓦片 | 引擎 BSD-3-Clause；样式、字体、瓦片和地形各自有授权；Key 依提供方 | 原生事件、Marker 与相机控制可联动 Vue；适合复杂矢量样式 | WebGL 带来更强样式能力，也增加 GPU/Worker/CSP 与低端设备验证成本 | 世界扩展灵活，但开源引擎不等于合法可用全球底图 |

以上性能为技术取舍，不是本项目基准测试结果。没有安装或下载 SDK，因此不存在 SDK 运行、节点定位或缩放通过的结论。

## 推荐接入路径

国内第一版优先评估高德或天地图的正式服务底图；八节点不需要自行管理全国行政区 GeoJSON。项目负责人确认账户授权、上线用途、域名与额度后再选定提供方。高德官方建议安全密钥通过服务代理配置，不将服务端秘密打包入 VITE 变量；本轮禁止改后端及服务配置，因此不擅自搭建代理。

将来建立独立地图组件，通过 cityId 与页面共享选中状态；坐标附来源和坐标系，不能混用 WGS84/GCJ-02。地图加载失败自动保留完整列表；无需地图也可完成全部内容阅读。移动端保留列表替代、触摸按钮与键盘选择，不依赖 hover。资源按路由懒加载，离开时清理实例、事件与请求。

## 中国地图部署核验

《地图管理条例》第 8–12、15、21–22 条涉及地图表示、公开地图审核及审图号等要求。上线前需要针对实际发布形态核查适用要求，使用服务商合规底图并不由本报告自动豁免发布方责任。保留底图来源、版权与审图信息，不遮挡、裁去必要附图或自行更改国界/行政区界线；不以“装饰图”代替准确版图。开放世界地图也需重新核查边界表达与来源。
