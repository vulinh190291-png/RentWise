## 安全降级与后续接入设计

地图组件后续接收城市与选中 ID，只发出城市选择事件；不自行维护第二套选中城市。状态区分未配置、加载中、可用、失败，后三种状态只在实际 SDK 实现后启用。未配置不发出第三方请求，目录始终可用。

授权确认后再开发懒加载 SDK、超时/失败降级、卸载销毁和事件清理。桌面地图与详情并排；手机显式地图/列表切换，地图不默认捕获页面滚轮，选择后进入现有详情。减少运动时不执行相机动画。保留版权及审图信息，不定制隐藏这些信息的样式。

坐标待正式平台确认后逐城核验：记录来源地址、获取日期、坐标系和城市中心点含义。城市中心不等同于文化住宅实例地址。未验证前不填写八城市经纬度，也不混用 WGS84 与 GCJ-02。

## 用户确认后的准备交付

- `mapSession.ts` 定义提供方无关适配器：选择城市、销毁实例、取消信号和选中回调。状态包含未配置/加载/可用/失败；支持超时、重试、加载中选中项回放、减少运动、迟到实例销毁及忽略过期事件。
- `MapAvailability.vue` 独立呈现状态与返回目录/重试事件。当前页面仅传入 unconfigured，不实例化任何地图会话；其余状态供后续真实适配器接入，不向用户虚报 ready。
- `map-preparation.mjs` 使用注入的适配器替身验证共享选择、未知 ID、空结果、回调、超时/失败/重试、迟到清理和减少运动；同时确认默认页面没有第三方请求。通过，但不等同于真实 SDK 测试。
- 组件拆分后 Explore 回归及 TypeScript/生产构建通过；前一轮同分支已通过首页两套及 8 项画像契约回归。未执行真实后端写入。
