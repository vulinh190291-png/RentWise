## 重跑浏览器回归
启动 `frontend` 的 `npm run dev -- --host 127.0.0.1`。测试脚本为 `frontend/tests/ui-home.mjs`，使用独立安装的 Playwright 和系统 Edge；不增加项目运行依赖。设置 PLAYWRIGHT_MODULE 指向可用 playwright 包，运行 `node frontend/tests/ui-home.mjs`。UI_BASE_URL 默认 http://127.0.0.1:5173；UI_SCREENSHOT_DIR 可指定截图目录。脚本的 API 拦截只在测试浏览器中使用，不写入产品逻辑。

## 第二轮真实联调与交付验收（2026-11-14，以本节为最新结论）

### 已实现
原 UI 实现保留。本轮仅将7个页面改为 Vue Router 懒加载，路由地址、认证守卫和业务行为不变；扩展回归脚本验证刷新/退出，新增显式创建专用账户的真实联调脚本 `frontend/tests/ui-real.mjs`。生产 bundle 的主要原因是 Element Plus 全量注册及此前所有页面静态导入。主 JS 从1117.58kB（gzip361.53）降至1014.49kB（gzip327.70），页面拆分成独立 chunk；500kB警告仍保留，不改依赖或阈值掩盖警告。

### 已验证（真实接口，非模拟登录）
最初缺少当前进程密钥，8080/8082/8083/8848未监听；MySQL80运行且3306开放。本机 Maven 离线启动还因缺少 Spring Boot 3.5.16 父POM失败。随后用户启动所需服务，全部端口开放，真实测试解除阻塞。

经Vite→Gateway→真实Learning注册专用账户，注册200、重复用户名409、错误密码401。正确登录取得JWT，users/me返回200；sessionStorage保持认证，刷新恢复用户，退出清除token，未登录访问dashboard返回login。重复submit事件只产生一次登录请求。
第二个专用账户完成10题真实诊断（测试答案），finish成功，Profile返回200且包含5类画像，Dashboard显示知识主题掌握度。诊断、画像、训练、测评入口导航成功。未直接执行SQL检查，用户持久化由实际配置的MySQL应用路径和注册/重复注册/登录读回验证；未声称查验了数据库表。

### 已验证（前端与故障注入）
1440/1024/768/390视口测量无水平溢出；桌面60/40、移动上下结构，输入区域独立稳定。已查看桌面、手机及真实Dashboard截图。轮播不清空输入，弹层Tab约束/ESC/焦点回退，空字段与注册密码一致性、reduced-motion、图片失败降级均通过。浏览器回归没有未捕获页面异常。
服务不可用用浏览器 route.abort(connectionrefused) 注入：错误提示可见、按钮恢复；没有停止用户服务，不能声称实机停服测试。
TypeScript独立检查 `vue-tsc -b frontend/tsconfig.json`、生产构建、扩展后的模拟回归均通过。真实脚本未使用route.fulfill伪造响应，只在最后的故障用例abort请求。

### 未验证与遗留问题

- 已验证学习入口与诊断初始化，未验证训练答题和阶段测评完整提交闭环。
